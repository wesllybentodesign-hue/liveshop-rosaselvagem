# Rosa Selvagem — Live Shop

Landing page de live commerce. HTML/CSS/JS puro, single-file.

## Deploy

Conecte este repositório ao Vercel. Nenhuma configuração adicional necessária — o `vercel.json` já cuida de tudo.

## Antes de cada live

1. Insira o embed do player em `index.html` (busque pelo comentário `<!-- Cole seu embed aqui -->`)
2. Atualize o título da live no header (busque por `Rosa Selvagem - Clareador de Manchas`)
3. Atualize o contador de viewers (`300`) se quiser
