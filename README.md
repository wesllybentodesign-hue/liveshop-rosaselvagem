# 🌸 Rosa Selvagem — Live Shop

Landing page de live commerce da marca **Rosa Selvagem**, otimizada para mobile.

## ✨ Funcionalidades

- Transmissão da live com frame congelado em proporção 9:16
- Avatar com anel animado estilo Instagram Live (CSS puro)
- 4 mini-cards de produtos em destaque com efeito glassmorphism
- Picture-in-Picture (PiP) ao rolar a página
- Grade de 12 produtos com links diretos para checkout (CartPanda)
- Single-file HTML — sem dependências externas além do Google Fonts

## 🚀 Deploy

Esta página é servida via **GitHub Pages** a partir da branch `main`.

URL pública: `https://<seu-usuario>.github.io/<nome-do-repo>/`

## 📁 Estrutura

```
index.html   → página completa (HTML + CSS + JS + assets em base64)
README.md    → este arquivo
```

## 🛒 Produtos

Os links de compra apontam para o checkout CartPanda da Rosa Selvagem.
Para atualizar um link, edite o `href` correspondente no `index.html`.
